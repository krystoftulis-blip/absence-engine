Every country has its own leave law, and today every entity tracks it in its own spreadsheet — so nobody can say whether the numbers are right. This page recomputes every balance from each entity's own law, shows which rule produced each figure, and points at where today's records disagree and probably why. It is one file: no system to log into, nothing to install.

What each entity's spreadsheet says, next to the law

The tool reads the file the entity keeps today — in its own format and its own language — recomputes the same people, and reports the gap. It runs alongside the current process and changes nothing, so it can be used before anything is migrated.

Where the numbers disagree

A negative delta means the entity is giving people less than they are owed. The last column is the point: an administrator cannot act on "−6", but can act on "this person is still on the 20-day tier".

What this changes

Today a balance is a number in a spreadsheet that nobody can check. Here it is a figure with the article of law that produced it attached, and a note wherever the local record disagrees.

unknown is a result, not a failure: where entitlement depends on documents the employer does not hold, the engine says so rather than assuming the lower figure — which is how an employer quietly under-grants six days a year for years.

delta is the local figure minus the recomputed one. Negative means the entity is under-granting.
